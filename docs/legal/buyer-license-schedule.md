# Buyer License and Rights Schedule

This schedule is a diligence checklist, not a substitute for a signed agreement or legal advice.

| Workstream          | Required completion before closing                                                                                                       |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| First-party source  | Confirm the owner’s right to transfer the differentiated domain modules and migrations                                                   |
| Contributors        | Obtain signed IP assignments and confidentiality records for every contributor or contractor                                             |
| Dependencies        | Attach the generated SBOM, license inventory, notices, and any source-offer obligations                                                  |
| Hosted services     | Record Supabase, model, gateway, email, storage, and monitoring terms and data-processing commitments                                    |
| Media and branding  | Record source and redistribution rights for fonts, icons, screenshots, logos, and demo assets                                            |
| Customer data       | Confirm that evaluation fixtures are synthetic and no customer data is included                                                          |
| Buyer grant         | Execute the definitive assignment, exclusive license, or non-exclusive license with field, territory, term, support, and indemnity terms |
| Post-close controls | Transfer secrets through a managed vault, rotate credentials, and update ownership and incident contacts                                 |

The repository’s LICENSE file is intentionally a transaction notice. Counsel should replace it or supplement it with the final commercial grant before distribution.
